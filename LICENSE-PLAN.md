# LIFE OS — License Plan

## Current status

No software or documentation license has been selected yet. Until a license is added, the repository remains under the default copyright terms: all rights reserved.

## What needs a decision

Before the first public release, choose and document licenses for:

- **Source code:** a permissive or copyleft software license.
- **Documentation:** a documentation-friendly license.
- **Branding:** logo, wallpapers, icons, and other original visual assets may need separate terms.
- **Third-party assets:** preserve each upstream project's license and attribution requirements.

## Important

Do not assume that Arch Linux, KDE Plasma, XFCE, Python packages, fonts, icons, or wallpapers become part of one LIFE OS license. Each component retains its own licensing terms.

No license files or copyright permissions should be added until the project owner has reviewed and approved the choices.
