# LIFE OS — Vision

## Mission

Make computing simpler and more accessible for students through a calm, capable, and approachable Linux experience.

## Target audience

- School and college students
- Programming learners
- Students using older laptops
- People who want one computer for study, everyday work, and entertainment

## Desktop philosophy

LIFE OS takes inspiration from familiar desktop interactions found in macOS and Windows while developing its own original visual identity and interface.

The goal is familiarity without copying another operating system's branding or interface assets.

## Core experience

- A familiar application launcher and taskbar
- Straightforward file management and system settings
- Student productivity applications
- Local-first notes and planning
- Optional gaming tools
- Clear onboarding and useful documentation

## Principles

1. Simplicity over unnecessary features.
2. Performance over visual effects.
3. Reliability over frequent redesigns.
4. Privacy over unnecessary data collection.
5. Accessibility over technical complexity.
6. Honest compatibility claims backed by testing.

## Product boundaries

LIFE OS is both a Linux distribution project and a student-focused software ecosystem. Its companion applications should remain useful on supported Linux desktops even before a custom ISO is available.
